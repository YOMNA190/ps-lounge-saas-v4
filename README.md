# PS Lounge SaaS v4

A management product concept for PlayStation lounges, with a modern dashboard-oriented interface and Supabase-backed foundations.

## Overview

A PlayStation lounge management SaaS interface built with React, TypeScript, Supabase, and Tailwind CSS.

## Highlights

- SaaS dashboard foundation
- Supabase integration structure
- Reusable UI components
- Clear environment and deployment configuration

## Tech stack

React, TypeScript, Vite, Supabase, PostgreSQL, Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown by the development server. For a production build:

```bash
npm run build
npm run preview
```

## Available scripts

| Script | Command |
|---|---|
| `dev` | `vite` |
| `build` | `tsc -b && vite build` |
| `lint` | `eslint .` |
| `preview` | `vite preview` |

## Project structure

The application code lives in `src/`, static assets are served from `public/`, and the project configuration is kept at the repository root.

## Environment variables

Do not commit credentials or production secrets. Copy the example environment file when one is provided and keep local secrets in `.env.local`.
